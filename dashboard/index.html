The evidence: category multiples

Each multiple is the median market-cap / TVL of the category's tokenized protocols in this snapshot, winsorized to 0.01–10 and shrunk toward the global median with a weight of 5 phantom observations, so thin categories price near the market instead of on one print.

Already trading — kept off the board

These protocols' tokens exist, so the market names their value; the radar never ranks them. They appear here only as the comparables the multiples are learned from.

Implied value is this board's own claim: what a token would be worth if the protocol's record stayed as it is. It is not a prediction that a token will be issued, or when. A protocol here records no token in the snapshot; that is a statement about the record, not proof none exists.
